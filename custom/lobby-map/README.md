# Hub lobby map

The `minecraft:hub` dimension uses [Xemtori Small Party Lobby](https://www.curseforge.com/minecraft/worlds/xemtori-small-party-lobby/files/7882017) by XEMTORI. The original archive is at the server root as `Xemtori Small Party Lobby map.zip` (SHA-256: `17e02e6515ce44f5d7df1714da56f2eb9ae2b1cccb953398324df31a75f83b44`).

The map's `region/` and nonempty `poi/` files were imported into `world/dimensions/minecraft/hub/`. Its player data, world settings, datapacks, and other dimension files were not imported. The join spawn and BedWars main lobby point to `-61.5, -31, -49.5`, facing the center of the build. The archive's own spawn at `0, -60, 0` is outside the build.

The previous hub and the two changed plugin configs are backed up in `backups/hub-before-xemtori-20261019-231636/`. Stop the server before restoring or changing region files.
